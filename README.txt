MCDSaveEdit app files

Upload everything in this folder (index.html, manifest.webmanifest, sw.js and the icon PNGs) to the root of a website,
for example a GitHub Pages repository. Then open the site in Chrome on your phone and choose "Install app" / "Add to Home screen".

Your personal data file (mcd-data.json) is NOT part of these files on purpose: keep it on your phone and use
Menu > Import my data file inside the app.
